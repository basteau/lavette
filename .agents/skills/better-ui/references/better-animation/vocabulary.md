# Motion vocabulary

Use the closest term and explain it briefly. If the description is ambiguous,
offer one or two distinctions; do not force an effect into this list.

| Description | Useful term |
| --- | --- |
| Appears through changing opacity | Fade |
| Two states overlap as one fades out and the other in | Crossfade |
| Grows into place without overshoot | Scale-in |
| Grows slightly past its resting size, then settles | Pop-in or spring overshoot |
| Grows from the button that opened it | Origin-aware animation |
| Items appear one after another | Stagger |
| The same object travels between views or containers | Shared element transition |
| Existing elements move smoothly as layout changes | Layout animation |
| Shape changes continuously into another shape | Morph |
| A clipping boundary uncovers content | Clipped reveal |
| A gradient or image controls which parts show | Mask |
| Moves in direct relation to scroll position | Scroll-driven animation |
| Starts an entrance when content enters view | Scroll reveal |
| Foreground and background travel at different rates | Parallax |
| Drag resists beyond a boundary and returns | Rubber-banding |
| Released motion carries its speed forward | Momentum |
| Motion can reverse from its current state | Interruptible animation |
| Motion changes speed along its path | Easing |
| Constant progress through time | Linear timing |
| Settles through stiffness, damping, and mass | Spring |

Naming an effect does not recommend using it. Choose implementation and intensity
only when the user asks for design or code.
